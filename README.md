# App Generador de Avatares - Sicnova & IES Santo Reino

Esta es una aplicación web genérica diseñada para el **Instituto Santo Reino** por **Sicnova**.

## Características
- **Selector de edad**: Filtro de seguridad inicial.
- **Flujo Adulto**: Integración con motor de IA para crear avatares 3D realistas mediante foto.
- **Flujo Menor**: Reproducción de video educativo/informativo.
- **Interfaz**: Modo oscuro (Dark Mode) optimizado para dispositivos móviles.

## Cómo desplegar (GitHub Pages)
1. Sube el archivo `index.html` a un repositorio de GitHub.
2. Ve a **Settings** (Configuración) de tu repositorio.
3. En el menú izquierdo, busca **Pages**.
4. En "Build and deployment", selecciona la rama `main` y guarda.
5. GitHub te dará una URL segura (`https://...`). **Es obligatorio usar HTTPS para que la cámara funcione**.
